# Scriptolator Troubleshooting Guide

**Professional AI Narration**

**Version 1.0.0**

---

# Introduction

This guide provides solutions to the most common issues encountered when using Scriptolator.

Before contacting support, work through the relevant section below.

---

# Voices Do Not Load

## Symptoms

- The voice list is empty.
- "Unable to load voices" is displayed.

## Possible Causes

- No Internet connection.
- Temporary Microsoft Edge voice service issue.
- Firewall or security software blocking access.

## Solutions

1. Confirm your Internet connection is working.
2. Restart Scriptolator.
3. Verify that your firewall is not blocking Scriptolator.
4. Try again after a few minutes.

---

# Preview Produces No Sound

## Check the following:

- Windows volume is not muted.
- Speakers or headphones are connected.
- The correct playback device is selected.
- A valid narration voice has been chosen.
- Internet connectivity is available.

---

# MP3 Generation Failed

## Possible Causes

- Network interruption.
- Invalid output location.
- Destination file already open.
- Temporary voice service problem.

## Solutions

- Retry the generation.
- Save to another folder.
- Close applications using the destination MP3.
- Review the application log for additional information.

---

# Output Folder Cannot Be Opened

Verify that:

- The folder still exists.
- You have permission to access it.
- The drive is connected if using removable or network storage.

Choose a new output folder if necessary.

---

# Recovery Was Not Offered

Recovery information is only available if Scriptolator previously saved recovery data.

If no recovery is available:

- Check that recovery has not already been restored.
- Look in the recovery folder.
- Review the application log.

---

# Settings Were Not Remembered

Ensure Scriptolator has permission to write to its settings location.

Avoid running the application from read-only media.

---

# Application Will Not Start

Try the following:

1. Restart Windows.
2. Launch Scriptolator again.
3. Review the latest log file.
4. Reinstall Scriptolator if required.

---

# Log Files

Log files contain diagnostic information that can assist with troubleshooting.

When reporting a problem, include the relevant log file if possible.

---

# Still Need Help?

Consult:

- Quick Start Guide
- User Guide
- FAQ

If the problem persists, include:

- Scriptolator version
- Windows version
- Steps to reproduce the problem
- Relevant log files
