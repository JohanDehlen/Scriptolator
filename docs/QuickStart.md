# Scriptolator

**Professional AI Narration**

# Quick Start Guide

**Version 1.1.0**

---

## Welcome

Welcome to **Scriptolator**, a Windows desktop application that transforms written scripts into natural-sounding AI narration using Microsoft Edge or Microsoft Azure AI Speech voices.

This guide will help you create your first narration in just a few minutes.

---

# 1. Start Scriptolator

Launch Scriptolator from the Start Menu, Desktop shortcut, or by running `Scriptolator.exe`.

---

# 2. Create or Open a Script

Type directly into the **Script Editor** or choose **Script → Open** to load an existing text file.

---

# 3. Choose a Voice

In the **Voice Panel**:

- Choose **Microsoft Edge** for free narration without an Azure account, or **Microsoft Azure AI Speech** for Azure voices.
- Select a language.
- Select a narration voice.
- Adjust Speed, Pitch and Volume if required.

To use Azure for the first time, click **Configure Azure...**, enter the subscription key and region for your Azure Speech resource, and test the connection before saving.

Tip: Click the ☆ button to add frequently used voices to **Favorites**.

---

# 4. Preview the Voice

Select a sentence or paragraph and click **Preview**.

If no text is selected, Scriptolator previews the beginning of the script.

---

# 5. Generate MP3

Click **Generate MP3**.

Choose the destination file when prompted.

While narration is being created, the Generate button displays progress.

---

# 6. Listen

Click **Play MP3** to hear the finished narration, or **Open Output Folder** to locate the generated file.

---

# Projects

Save your work with **File → Save Project**.

Projects store:

- Script
- Voice
- Voice settings
- Selected profile
- Related project information

Narration Profiles also remember the selected speech engine, so an Azure profile can restore Azure and its saved voice automatically.

---

# Recovery

If Scriptolator closes unexpectedly, your work is automatically offered for recovery the next time the application starts.

---

# Helpful Tips

- Preview difficult names before generating long narrations.
- Create Voice Profiles for recurring narrators.
- Use Favorites to reduce scrolling.
- Save projects regularly.
