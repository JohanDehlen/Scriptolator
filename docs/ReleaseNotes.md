# Scriptolator Release Notes

## Version 1.0.0

# Welcome

Version 1.0.0 is the first official release of Scriptolator.

This release delivers a complete workflow for transforming written scripts into professional AI narration using Microsoft's Edge Neural voices.

---

# Highlights

## Professional Narration Workflow

- Create or import scripts
- Preview narration
- Generate MP3 audio
- Play completed narration
- Open the output folder directly

---

## Voice Management

- Microsoft Edge Neural voices
- Language filtering

- Speed, Pitch and Volume controls
