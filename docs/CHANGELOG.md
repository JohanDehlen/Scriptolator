# [1.0.0] - 2026-07

## Initial Public Release

### Added

- Professional Windows desktop interface.
- Microsoft Edge Neural voice integration.
- Script editor with open, save and clear functions.
- Project save and load support.
- Voice Profiles.
- Favourite Voices.
- Language filtering.
- Selected text preview.
- MP3 narration generation.
- Output folder management.
- Automatic project recovery.
- Application logging.
- Remembered output and script folders.
- Recent Projects menu.
- Professional application icon.
- Splash screen.
- PyInstaller build support.

### Changed

- Improved application startup.
- Improved file handling.
- Improved output naming.
- Improved voice browsing workflow.
- Improved settings persistence.
- Prepared application paths for executable deployment.

### Fixed

- Folder persistence issues.
- Output filename handling.
- Resource path handling for packaged builds.
- Generate workflow reliability.
- Script loading and saving refinements.
