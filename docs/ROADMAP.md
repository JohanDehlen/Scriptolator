# Scriptolator Roadmap

**Professional AI Narration**

This roadmap describes the long-term direction of Scriptolator. It is intended to communicate priorities rather than fixed delivery dates.

---

# Guiding Principles

Every new feature should satisfy at least one of the following:

- Improve narration quality.
- Improve workflow efficiency.
- Improve reliability.
- Improve usability.

Features that do not support Scriptolator's core purpose—creating professional AI narration—should be avoided.

---

# Version 1.0.x

Focus: Stability and polish.

Planned priorities:

- Bug fixes
- Performance improvements
- User interface refinements
- Documentation updates
- Installer improvements
- Accessibility improvements

---

# Version 1.1

Focus: Workflow enhancements.

Candidate features:

- Pronunciation dictionary
- Voice search
- Batch narration generation
- Improved project browser
- Faster preview workflow
- Additional export options

Priorities will be based on real-world usage and feedback.

---

# Version 1.2

Focus: Power-user capabilities.

Possible enhancements:

- Batch queue management
- WAV export
- FLAC export
- Voice comparison tools
- Advanced project metadata

---

# Version 2.0

Focus: A mature narration workspace.

Long-term ideas include:

- Narration history
- Project analytics
- Enhanced production workflow
- Collaboration-ready project structure

Features will only be added if they reinforce Scriptolator's core mission.

---

# Philosophy

Scriptolator is intentionally focused.

It is not intended to become a video editor, audio editor, or AI writing assistant.

Its purpose is to provide the fastest, most reliable path from script to professional AI narration.
