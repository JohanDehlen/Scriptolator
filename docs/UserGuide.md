# Scriptolator

**Professional AI Narration**

# User Guide

**Version 1.1.0**

---

# 1. Introduction

Scriptolator is a Windows desktop application for creating high-quality AI narration from written scripts using Microsoft Edge and Microsoft Azure AI Speech voices.

It is designed for creators who need a fast, repeatable workflow from script to finished MP3.

---

# 2. Main Window

The main window is divided into three working areas:

- **Menu Bar** – access projects, scripts, settings and help.
- **Script Editor** – write or edit narration text.
- **Voice Panel** – choose voices, create favourites and profiles, and preview narration.

The status bar reports the progress of long-running operations such as narration generation.

---

# 3. Working with Scripts

You can:

- Create a new script.
- Open an existing text file.
- Save changes to a script.
- Clear the editor.

Scriptolator remembers the last folder used for opening scripts to speed up future work.

---

# 4. Speech Engines and Voices

Use the **Speech Engine** list to choose:

- **Microsoft Edge** – free Microsoft voices that do not require an Azure account.
- **Microsoft Azure AI Speech** – Azure voices, including multilingual voices such as Jorge Multilingual.

Before selecting Azure for the first time, click **Configure Azure...** and enter the subscription key and region for your Azure Speech resource. Scriptolator stores the key securely in Windows Credential Manager.

Use the **Narration Language** list to filter voices by language.

Use the **★ Favorites** filter to show only your favourite voices.

Click the **☆ / ★** button beside the voice list to add or remove favourites.

---

# 5. Voice Profiles

Voice Profiles store:

- Speech engine
- Voice
- Speed
- Pitch
- Volume

Profiles are ideal when you regularly create the same style of narration.

---

# 6. Projects

Projects save your complete working session, including:

- Script
- Selected voice
- Voice settings
- Profile
- Project metadata

Use **File → Save Project** regularly.

---

# 7. Generating Narration

1. Prepare your script.
2. Select a speech engine.
3. Select a voice.
4. Preview if required.
5. Click **Generate MP3**.
6. Choose the output filename.
7. Wait for generation to complete.
8. Play the finished narration or open the output folder.

---

# 8. Recovery

If Scriptolator closes unexpectedly, unsaved work is detected and can be restored automatically when the application starts again.

---

# 9. Logs

Diagnostic logs are written automatically to help diagnose unexpected problems.

These files are primarily intended for troubleshooting.

---

# 10. Tips and Best Practices

- Keep paragraphs reasonably short.
- Preview difficult names before generating a long narration.
- Use Voice Profiles for recurring projects.
- Save Projects instead of relying solely on recovery.
- Use Favorites to reduce scrolling through the voice list.
